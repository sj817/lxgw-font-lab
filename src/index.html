一、字体是朗读者的嗓音

同一段文字，用黑体排出来，像新闻播音员在念稿；换成宋体，像一位老编辑在灯下校对；换成楷体，就成了朋友寄来的一封信。字形之间的差别很细，但它会悄悄决定读者用什么心情读下去。

这也是「霞鹜」三款字体有意思的地方：文楷带着手写的温度，新晰黑干净克制，新致宋保留了刻本的骨架。把它们放进同一个界面里比较，远比只看一张字样海报更能说明问题。

二、三款字体从哪里来

霞鹜文楷衍生自 Fontworks 的 Klee One。Klee One 原本是一款日文教科书风格的字体，笔画带着铅笔书写的轻重变化；霞鹜文楷在此基础上补全了大量汉字，以 SIL Open Font License 1.1 发布，可以免费商用，但不得单独售卖字体文件。

霞鹜新晰黑与霞鹜新致宋分别衍生自 IPAex 黑体，以及 IPAex 明朝和 IPAmj 明朝。作者把这些按日本写法设计的字形逐一改成中国大陆的规范写法。它们遵循 IPA Font License 1.0：嵌入网页或应用时，需要附上授权协议，并告诉用户如何换回原始的 IPA 字体。

作者署名「落霞孤鹜」，字体也以「霞鹜」为名。读到这四个字，很难不想起王勃的这一句。

三、在界面里各自适合什么

  • 文楷：阅读类产品、笔记、博客正文、引文与签名区。在按钮、表格这类信息密集的地方，手写感会显得有些松散。
  • 新晰黑：通用界面字体的有力候选，字面清晰、灰度均匀，十二像素下依然好认。
  • 新致宋：长篇阅读、标题和带出版物气质的页面。横细竖粗的笔画在低分辨率屏幕上更考验渲染。

当然，这些只是经验之谈。真正的判断应该在你自己的屏幕上做出，这正是本页存在的理由。

屏幕阅读的几个数字

  1. 正文字号 16–18 px，行高 1.7–1.9 倍。中文没有升部和降部，比西文需要更宽松的行距。
  2. 每行 30–40 个汉字最适合连续阅读；超过 45 个字，眼睛换行时容易读串。
  3. 段落之间留出大约一个字高的空白，或者首行缩进两个字，二者选一种即可。

网页里加载中文字体时，常用 font-display: swap 先显示系统字体、再替换成网络字体；本页的字体切换也是这样，所以刚打开时会闪一下。想在页面里查找文字，按 Ctrl + F 即可。文中提到的版本号，以本页实际加载的字体文件为准[1]。

常见问题

ACCORDION
为什么切换字体时会闪一下？

字体解码完成之前，浏览器先用系统字体顶上，就绪后再替换，这就是 font-display: swap 的效果。内嵌的字体一般几十毫秒就能就绪。

子集里包含哪些字？

本页出现过的全部字符随 HTML 内嵌；你在输入框里打出页面没有的字时，再按需下载 GB2312 一级字（3755 个）和二级字（3008 个）的扩展字表。

可以商用吗？

文楷遵循 OFL 1.1，可以商用但不得单独售卖字体文件；新晰黑、新致宋遵循 IPA 1.0，嵌入网页或应用时需附上协议，并提供换回原始字体的方法。

手机上看起来和电脑上不一样？

是的。系统的抗锯齿、屏幕像素密度和默认字号都会影响观感，最好在两种设备上都打开本页对比。
